Sky Rush is a side-scrolling flight game: steer a little red plane through gold rings, dodge birds and hot-air balloons, chain pickups into combos, and survive twelve rising levels of speed.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Steer with arrows or WASD, or drag the plane. Shift is boost. Enter starts, P pauses.
