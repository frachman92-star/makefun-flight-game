Sky Rush is a pseudo-3D chase-view flight game: fly a red aircraft over patchwork fields, a winding river and a little town, through glowing gold rings, past birds and hot-air balloons, with a lit instrument HUD (altitude, speed, heading, throttle, fuel, damage). Four missions rotate: Ring Run, River Run, Touchdown (land on the runway), and Waypoint Dash against the fuel gauge.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. W / S work the throttle, A / D or Left / Right bank, Up / Down pitch, or drag to steer. Enter starts, P pauses.
